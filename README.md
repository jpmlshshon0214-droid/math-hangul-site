# 수식한글

PDF에 이미 저장된 텍스트와 수학 기호를 추출해 한글에서 열 수 있는 HWPX로 저장하는 무료 웹앱입니다. Mathpix 등 유료 OCR/API는 사용하지 않습니다.

## 무료 버전의 범위

- 텍스트를 마우스로 선택할 수 있는 PDF를 지원합니다.
- 스캔본처럼 페이지가 이미지로만 된 PDF는 OCR하지 않습니다. 그런 파일은 업로드 후 안내 오류가 표시됩니다.
- PDF의 수식이 텍스트/유니코드 기호로 들어 있으면 추출되지만, 원본의 분수·첨자·배치와 페이지 디자인은 완벽히 복원되지 않을 수 있습니다.
- 파일은 서버 메모리에서 처리하고 변환 후 결과를 제공합니다. Render 무료 서비스는 15분 유휴 시 잠들고 다음 접속 때 깨어나므로 첫 접속이 느릴 수 있습니다. 무료 플랜의 용량/사용량 제한도 적용됩니다.

## 로컬 실행

Python 3.10 이상이 필요합니다.

```powershell
cd outputs/math-hangul-site
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

브라우저에서 `http://127.0.0.1:8000`을 여세요. HTML 파일을 직접 열면 API 서버에 연결되지 않습니다.

## 누구나 쓸 수 있게 무료 공개 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render에서 **New → Blueprint**를 눌러 저장소를 연결합니다.
3. `render.yaml`에 따라 무료 웹 서비스가 배포됩니다. API 키나 결제 정보는 설정하지 않습니다.
4. 배포가 끝나면 Render가 제공하는 HTTPS 주소를 공유합니다.

GitHub 계정과 Render 계정은 필요합니다. 두 서비스의 무료 사용량/약관은 바뀔 수 있습니다. Render 무료 웹 서비스는 15분 동안 요청이 없으면 잠들며, 다시 접속할 때 약 1분이 걸릴 수 있습니다. 무료 플랜 한도에 도달하면 해당 기간에 서비스가 정지될 수 있습니다.

## 변환 및 라이선스

HWPX 생성에는 `pyhwpxlib`를 사용합니다. 프로젝트 README에 따르면 관련 파일 대부분은 BSL 1.1이며 개인/비상업/교육/오픈소스 사용은 무료이고 상업 이용에는 별도 라이선스가 필요할 수 있습니다. 광고, 유료 제공 등 상업적 이용 전에 라이선스 조건을 확인하세요.
